# LEVEL MASTER · Zona 1 · Praderas Pixel v1.0

Prototipo jugable autocontenido de la primera zona completa (20 mundos).

## Cómo usar
1. Abrí `index.html` en un navegador moderno.
2. Para publicar en GitHub Pages:
   - Crear un repositorio (por ejemplo `level-master`)
   - Subir `index.html`
   - Settings → Pages → Deploy from a branch → `main` / root
3. Abrir la URL pública generada por GitHub Pages.

## Controles
- Izquierda: A o ←
- Derecha: D o →
- Salto: W o ↑
- Mobile: controles táctiles

## Qué incluye
- 20 mundos progresivos
- Día / atardecer / noche
- 6 personajes: Vexa, Miko, Tali, Runo, Zako y Eren
- Monedas, estrella y puntuación
- Saltarines y Voladores
- Plataformas móviles y que caen
- Mundo 20 con Gran Saltarín y 3 interruptores
- Portal Master
- Guardado local del progreso
- Sonidos sintetizados con Web Audio
- Sin assets externos pesados

## Peso
La Zona 1 está implementada casi totalmente con Canvas/CSS/JS para preservar el presupuesto global de 25 MB del juego completo.
