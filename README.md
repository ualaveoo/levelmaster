# Level Master — 10 mundos · 120 niveles

Versión de prueba integral.

- 10 mundos, 12 niveles por mundo.
- Cada mundo utiliza una gramática de nivel, ambientación, enemigos, obstáculos y salida propia.
- Mundo 1 conserva la línea visual aprobada de Praderas Verdes.
- Selección visible entre 6 personajes: Vexa, Miko, Tali, Runo, Zako y Eren.
- Perfiles múltiples y alias únicos en el navegador.
- Progreso guardado por jugador, mundo y nivel mediante localStorage.
- Música diferenciada por mundo, efectos de sonido y pausa.
- Escalado automático para visualizar el escenario completo al 100% de zoom del navegador.

Nota: la sincronización de un mismo perfil entre dispositivos requiere un backend externo; GitHub Pages por sí solo guarda el progreso en cada navegador.
