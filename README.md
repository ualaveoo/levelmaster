# Level Master · Prototipo jugable

Primera vertical slice de Level Master con 3 mundos de Zona 1 · Praderas Pixel.

## Incluye
- Portada con alias del jugador
- Selección de Vexa, Miko, Tali, Runo, Zako y Eren
- Progreso local con localStorage
- Mundo 1 día, Mundo 2 atardecer, Mundo 3 noche
- Controles desktop: A/←, D/→, W/↑/Espacio
- Controles táctiles para móvil
- Recomendación de orientación horizontal en móvil
- Monedas, estrella y puntaje
- Saltarín y Volador
- Pozos, plataformas fijas, móviles y plataforma que cae
- Portal Master
- Efecto POF/¡CASI! y reinicio rápido
- Pantalla de resultado y mejor puntuación por mundo

## Publicar en GitHub Pages
1. Crear un repositorio, por ejemplo `level-master`.
2. Subir `index.html` a la raíz del repositorio.
3. En GitHub abrir **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Elegir la rama `main` y carpeta `/ (root)`.
6. Guardar. GitHub mostrará la URL pública del juego.

## Nota
Este prototipo usa figuras pixeladas generadas con CSS para validar la jugabilidad y mantener el archivo muy liviano. Los sprites visuales definitivos de los seis personajes se pueden sustituir después sin cambiar la lógica del juego.
