# LEVEL MASTER · Zona 1 · Praderas Pixel — Versión final de prueba

## Qué incluye
- 20 mundos jugables.
- Sin sistema de vidas.
- Controles:
  - Flecha izquierda o A: izquierda
  - Flecha derecha o D: derecha
  - Flecha arriba o W: saltar
- Desktop: pensado para navegador al 100% de zoom.
- Mobile: adaptación horizontal con controles táctiles.
- Progresión de ambientes: praderas, cascadas, atardecer, noche y Portal Master.
- Más variedad de obstáculos: plataformas móviles, trampolines, plataformas que caen, viento, ascensores, llaves y puertas.
- Mundo 20: 3 Llaves Master visibles; al obtener 3/3 el Gran Saltarín se retira y el Portal se abre.
- Portada aprobada incrustada en el propio HTML para evitar rutas rotas.
