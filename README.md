# LEVEL MASTER · Zona 1 · Praderas Pixel v2.2

Versión autocontenida en un único HTML.

Las tres imágenes aprobadas están incrustadas dentro de `index.html`, por lo que:
- no depende de una carpeta `assets`;
- puede abrirse directamente;
- funciona mejor al compartirlo;
- queda listo para GitHub Pages.

## Controles
- A o ← = izquierda
- D o → = derecha
- W o ↑ = salto
- Mobile = controles táctiles

## GitHub Pages
Sube simplemente `index.html` al repositorio y activa GitHub Pages.
