# LEVEL MASTER · Versión final de juego base

- 10 mundos.
- 12 niveles por mundo (120 niveles en total).
- Mundo 1: Praderas Verdes.
- Mundo 2: Bosque Encantado.
- Mundo 3: Cuevas Profundas.
- Mundo 4: Desierto Ardiente.
- Mundo 5: Torres del Cielo.
- Mundo 6: Pantanos Tóxicos.
- Mundo 7: Montañas Heladas.
- Mundo 8: Volcán Infernal.
- Mundo 9: Laboratorio Secreto.
- Mundo 10: Castillo Oscuro.

Cada mundo tiene identidad visual, enemigos y obstáculos propios, y la dificultad progresa dentro de sus 12 niveles. Incluye variaciones de iluminación, oscuridad y niebla; efectos de sonido; música sintetizada por mundo con control independiente; pausa; y perfiles locales con alias únicos y progreso separado.

Controles: ← / A izquierda · → / D derecha · ↑ / W saltar.

## Perfiles
La versión de GitHub Pages guarda varios perfiles y su progreso en el navegador mediante localStorage, y evita alias repetidos en ese navegador. Para sincronizar el mismo perfil entre distintos dispositivos se necesita conectar un backend online (por ejemplo Supabase o Firebase); GitHub Pages por sí solo no sincroniza datos entre dispositivos.
