# LEVEL MASTER · Zona 1 · Praderas Pixel

Build limpio para GitHub.

## Controles
- Flecha izquierda o **A**: izquierda
- Flecha derecha o **D**: derecha
- Flecha arriba o **W**: saltar
- En móvil aparecen controles táctiles.

## Zona 1
20 mundos agrupados en 5 capítulos, con progresión de dificultad y mecánicas nuevas: Saltarines, Voladores, plataformas móviles, trampolines, plataformas que caen, plataformas temporales, viento, ascensores, llaves y puertas.

## Mundo 20
El objetivo es reunir 3 Llaves Master visibles. Se recogen tocándolas. Con 3/3, el Gran Saltarín se aparta y se abre el Portal Master.
