LEVEL MASTER · ZONA 1 · PRADERAS PIXEL
ÚLTIMA VERSIÓN DE PRUEBA

Incluye:
- Portada definitiva corregida:
  * Flechas para moverse
  * W para saltar
  * X para interactuar
- 6 personajes seleccionables
- 20 mundos jugables
- Día, atardecer y noche
- Monedas y estrellas
- Saltarines y Voladores
- Plataformas móviles y obstáculos progresivos
- Mundo 20 corregido:
  * tocar las 3 antorchas
  * progreso 1/3, 2/3, 3/3
  * el Gran Saltarín se retira
  * se abre el Portal Master
- Progreso guardado en navegador

CONTROLES
- Izquierda: Flecha izquierda o A
- Derecha: Flecha derecha o D
- Saltar: W o Flecha arriba
- Interactuar: X cuando corresponda

ARCHIVO
- index.html es autocontenido.
- No depende de carpetas de assets.
- La portada está incrustada en WebP.
